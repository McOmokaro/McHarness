# Download & Install

McHarness installs with a single command. It is one native binary that lives on your machine — no web app, no hosted database, no VPS required.

## One-line install

```bash
curl -fsSL https://McOmokaro.github.io/McHarness/install.sh | bash
```

:::note Placeholder
The install script is not published yet — McHarness is under active development. This command is the shape the installer will take. Watch the [Roadmap](/roadmap) for the release.
:::

## What you get

- **A native terminal agent** — runs where you run, not on someone else's server.
- **The Key Farm** — bring any provider, any key, any model; they act as one pool.
- **Fusion & Fission** — the skill and plugin cores, compiled in.
- **Three-strata memory** — persistent, working, and skill memory in the core.
