# Plugins — Fission

**Fission** is the plugin core of McHarness. It carries the same unified, domain-addressed, one-command-update model as [Fusion](/skills) — but for plugins.

## One model, two cores

Where Fusion compiles skills into the organism, Fission extends it. A plugin is not a bolt-on that fights the core; it is addressed the same way a skill is, and it updates with a single command. No dependency hell, no version matrix to reconcile by hand.

## One-command update

Plugins move as one unit. You update the harness, and the plugin surface moves with it — no per-plugin upgrade dance.

## Built to stay whole

The "Whole" law applies here too: a plugin should feel like part of the organism, not a foreign body wired in through a fragile interface. See [Architecture](/architecture) for how the cores interlock.
