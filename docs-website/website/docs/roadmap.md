# Roadmap

## 📍 Phase 1: Foundation
- [ ] Core harness engine (task scheduling, agent spawning)
- [ ] Configuration as code (YAML/TOML profiles)
- [ ] Basic lifecycle hooks (spawn, run, complete, fail)

## 📍 Phase 2: Observability
- [ ] Distributed tracing across agent boundaries
- [ ] Real-time metrics dashboard
- [ ] Log aggregation and search

## 📍 Phase 3: Multi-Model Support
- [ ] Provider-agnostic model connectors (OpenAI, Anthropic, Cohere)
- [ ] Model fallback and circuit breaker patterns
- [ ] Token usage billing and metering

## 📍 Phase 4: Collaboration
- [ ] Shared memory spaces between agents
- [ ] Distributed harness execution (remote workers)
- [ ] Permission and capability gating

## 📍 Phase 5: Ecosystem
- [ ] Package marketplace for reusable agents
- [ ] Integration framework for external tools
- [ ] Versioned workflow definitions
