# Skills — Fusion

**Fusion** is the unified skill core of McHarness. Every skill the harness carries was reverse-engineered from a best-in-class open-source agent, re-forged natively, and compiled straight into the binary.

## Addressed by domain, not command syntax

You do not memorize a command tree. You state what you want, and the relevant skills are already armed. Fusion resolves intent to capability by **domain** — the same way a person reaches for the right tool without reciting its part number.

## Compiled in, not loaded from a folder

A skill in McHarness is not a plugin you install and hope resolves. It is a native subsystem. That is what keeps tool use at light speed: there is no interpreter, no dynamic discovery, no round-trip between your intent and the action.

## Provenance is public

Every skill traces back to the agent it was forged from, recorded in [The Forge Ledger](/the-forge) with a status of `studied → extracting → forged → merged`. Nothing is copied silently; the lineage is in the open.

:::info Featherweight
Skills follow the Omarchy philosophy: a capability you never invoke never lands on disk. The base stays tiny; the agent grows only where you use it.
:::
