**Forge target:** `mch-browser` (3D engine backend), `mch-tui` (visual dashboard), `mch-cyber` (3D asset generation for reports).

## What it is

67.js is a **3D engine for AI agents** (and for web pages). It has a real-time rasterizer, a path tracer, addons for terrain, vegetation, characters, liquid, vehicles, media export, and an **MCP server**. A scene is plain data: each part has a geometry, a matrix, and a material.

An **agent builds and changes a scene through the MCP server**, looks at PNG previews, and renders stills or MP4 video. The goal: "as capable as Blender, as light as three.js."

**MCP Server** (`packages/engine/`, `67js-mcp`):
- Connects agent to persistent browser renderer
- Needs local Chrome installation (`--backend gpu` for WebGL2, `--backend cpu` for CPU fallback)
- Agent writes JSON recipes, sets lights/fog, imports GLB assets, adds motion
- Agent gets PNG previews, compares up to 4 views in review grid, runs render jobs for stills/MP4 video
- Server accepts no arbitrary code, no remote asset URLs

**CLI / Render:**
- `npm run render -- --kind image --scene nature --backend gpu --preset high --output artifacts/nature.png`
- Video export streams one frame at a time (no full video in memory)

## Crown Jewels

1. **Agent-Native 3D Engine** — Designed from the ground up for AI agents to drive via MCP. Scene is plain data (geometry + matrix + material per part). Agent builds scene via MCP tools, gets PNG previews, iterates.

2. **Dual Renderer** — Real-time rasterizer (WebGL2/WebGPU) + path tracer (CPU/GPU). Agent chooses rasterizer for speed, path tracer for photorealism.

3. **MCP Server as First-Class Citizen** — Not an afterthought. The MCP server is the primary interface. Agent writes JSON recipes, gets PNG previews, compares up to 4 views in review grid, runs render jobs for stills/MP4.

3. **Addon System** — Modular imports. Agent loads only what it needs (terrain, vegetation, physics, vehicles, liquid, characters, networking, etc.). Keeps bundle small.

4. **Agent-First Asset Pipeline** — `build-67js-scene` skill for scenes/materials, `render-67js-media` skill for image/video export. Agent writes JSON recipes, imports GLB assets, adds motion, gets PNG/MP4 back.

4. **Deterministic Scene Format** — Scene is plain JSON (geometry + matrix + material per part). Deterministic, version-controllable, diffable.

5. **MCP Server with Preview Loop** — Agent gets PNG previews, compares up to 4 views in review grid, runs render jobs for stills/MP4. No arbitrary code execution, no remote asset URLs.
