# McHarness Python Bridge (v0.0.1)

Research and data-collection tooling that bridges into the Rust core.

- `bridge.py` — the core bridge (studio: talk to the model layer)
- `ingest/` — the research half of the Ingestor

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```
